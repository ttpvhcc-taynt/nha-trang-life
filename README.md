# Nha Trang Life

Game 3D chơi trên trình duyệt, mô phỏng một kỳ nghỉ chậm ở Tây Nha Trang. Không cần tài khoản. Tiến trình và tủ đồ nằm trên máy bạn.

## Cách chơi

- **Start** để vào biệt thự.
- **W / S** tiến lùi, **A / D** rẽ trái phải. Trên điện thoại dùng cần điều khiển góc dưới.
- Đi tới vòng tròn trên đất rồi bấm **Ghé** để ăn, ngủ, làm việc, khám.
- **Tủ đồ**: chọn áo/quần có sẵn, hoặc **Thêm ảnh vào tủ** từ ảnh trên máy. Ảnh chỉ lưu trong trình duyệt (IndexedDB), không gửi lên mạng.
- Gom 6 bưu thiếp trong **Nhật ký**.

Nhân vật luôn mặc đồ.

## Chạy máy

```bash
npm install
npm run dev
```

Mở trang mà lệnh dev in ra. Bản dựng xuất bản: `npm run build`.
